<h2 id="method">Method</h2>

A low sliding push measures the product of mass and friction, and tipping the object measures mass and CoM height. Together they give all three parameters. Pressing down before pulling keeps the pivot in place on objects that would slide or spin under a conventional forward push.

<aside class="my-6 rounded-xl border-l-4 border-emerald-600 bg-emerald-50 p-5 text-base dark:bg-emerald-950/30">
  <strong>Assumptions and limitations.</strong> Planar CoM coordinates are supplied by prior pushing-based estimation; this stage recovers mass, CoM height, and table friction. The top contact and pivot must be visible and reachable, the fingertip must hold without slipping, and the pivot-to-CoM geometry must stay approximately rigid. Friction recovery additionally requires a low push that slides before tipping. Four objects establish feasibility; the boundary for base roundness and compliance is not yet characterized.
</aside>

<details class="my-6 rounded-xl border border-zinc-200 p-4 dark:border-zinc-700">
  <summary class="cursor-pointer text-base font-semibold">Why pressing helps, and how the fit works</summary>

An object tips before it slides when $F_\text{tip} < F_\text{slide} = \mu_t N$. A downward press increases the normal force to $N = mg + F_\text{press}$, raising the sliding threshold while a pull along an arc tips the object about its near edge.

<Figure>
  <div slot="figure" class="max-w-xl rounded-xl bg-white p-4"><Picture src={fig1} alt="Force diagram: downward press and tangential pull tip an object about its near bottom edge, with gravity, friction, and normal forces labeled." /></div>
  <Fragment slot="caption">The press stabilizes the pivot; the pull produces the tipping motion.</Fragment>
</Figure>

The measured F/T wrench is transformed to the pivot frame using the sensor pose from proprioception. The finger contact point does not need to be localized for this transformation:

$$
{}^{O}\mathbf{w}_\text{app} = -\mathrm{Ad}_{T_{SO}}^{\!\top}\;{}^{S}\mathbf{w}_\text{meas}
$$

The ground reaction acts through the pivot, so its moment about the pivot edge vanishes. A quasistatic torque fit over the tilt sweep recovers $(m,z_c)$, given the planar CoM input. The sliding measurement then resolves $\mu_t$ using the recovered mass.

**Force measurement in the released code.** The paper motivates friction recovery through slip onset. The released offline implementation uses a filtered median over a steady-sliding window; the website's friction results use that implementation. Its reference friction is computed from the same push using the independently measured mass, rather than from a separate friction trial.

</details>

<details class="my-6 rounded-xl border border-zinc-200 p-4 dark:border-zinc-700">
  <summary class="cursor-pointer text-base font-semibold">Abstract</summary>

Recovering physical properties of unknown objects through non-prehensile interaction is challenging because no single manipulation primitive reveals all relevant parameters. Planar pushing couples mass and friction, while conventional tipping cannot recover friction and may fail entirely when low-friction or curved-base objects slide or rotate instead of tipping. We introduce a multi-modal estimation framework that combines a sliding interaction with a press-and-pull tipping primitive to recover object mass, center-of-mass height, and surface friction. The press-and-pull interaction increases the object–table sliding threshold and stabilizes the pivot, enabling controlled tipping without any prior geometric object model. Wrist force/torque sensing, RGB-D perception, and robot proprioception are fused to estimate the physical parameters from the two complementary interaction modes. Experiments on an ABB IRB120 across four objects with varied geometry, mass, center of mass, and friction achieve low relative error, while successfully operating on curved-base objects that fail under conventional forward tipping. The results demonstrate that complementary non-prehensile interactions can recover a compact set of physical parameters without grasping, a prior object model, or learned interaction dynamics.

</details>

<h2 id="code">Code and data</h2>

The <a href={CODE_URL}>project repository</a> contains this website and a <a href={PACKAGE_URL}>Python package</a>: the <a href={ESTIMATOR_URL}>estimator</a>, <a href={SANDBOX_URL}>MuJoCo sandbox</a>, all 40 press-and-pull trials, and four sliding pushes. No robot or ROS installation is needed for offline evaluation.

```bash
git clone https://github.com/hylander2126/press-pull-tipping.git
cd press-pull-tipping
pip install -e ./code
python code/run_offline_eval.py --object all -q
python -m press_pull_estimator.sim.press_pull_sandbox
```

The offline evaluation reproduces the rounded values in Table 2. The simulator accepts options such as `--mass 1.1 --com-z 0.11`, `--object slab`, and `--viewer`.
